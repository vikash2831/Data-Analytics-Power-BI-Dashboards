💳 UPI User Usage Analysis Dashboard (Power BI)

📌 Project Overview

This project presents an **interactive UPI User Usage Analysis Dashboard** developed using Power BI, based on a dataset containing **2,000 user records** with **13 columns**.
The dashboard analyzes user behavior, transaction patterns, app preferences, and risk insights in digital payments.

---

📁 Dataset Details

* 📄 File: `UPI_User_Usage_Data.xlsx`
* 📊 Total Records: **2,000 rows**
* 🧾 Total Columns: **13**

Columns Included:

* user_id
* age_group
* city
* city_tier
* kyc_status
* account_age_days
* linked_bank_count
* avg_monthly_transactions
* avg_transaction_value
* preferred_app
* preferred_device
* user_loyalty_score
* is_high_risk_user

---

🔧 Data Processing

* Cleaned missing/null values
* Standardized categorical columns
* Calculated:

  * Average monthly transactions
  * Average transaction value
  * Average account age
* Grouped data by:

  * Age group
  * Preferred app
  * Device type
  * City tier
* Filtered risk users for better insights
