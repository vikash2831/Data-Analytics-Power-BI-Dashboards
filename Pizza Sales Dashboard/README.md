🍕 Pizza Sales Performance Dashboard (Power BI)

📌 Project Overview

This project showcases an **interactive Pizza Sales Dashboard** built using Power BI, analyzing **48,620 transaction records**.
It provides insights into sales trends, customer ordering behavior, and product performance.

---

📁 Dataset Details

* 📄 File: `Pizza_Sales_Data.xlsx`
* 📊 Total Records: **48,620 rows**

🧾 Columns Included:

* pizza_id
* order_id
* pizza_name_id
* quantity
* order_date
* order_time
* unit_price
* total_price
* pizza_size
* pizza_category
* pizza_ingredients
* pizza_name

---

🔧 Data Processing

* Converted **order_date & order_time** into proper format
* Created:

  * Month-wise hierarchy
  * Category-based aggregations
* Calculated:

  * Total Orders
  * Total Sales
  * Average Unit Price
* Cleaned and formatted currency values

---

📊 Dashboard Features

🔹 Key Performance Indicators (KPIs)

* 📦 Total Orders: **48.62K**
* 💰 Total Sales: **817.86K**
* 💲 Average Unit Price: **16.49**
* 🍕 Most Ordered Size: **L**

---

🔹 Visualizations

📈 Orders by Month

* Shows monthly order trends
* Helps identify peak and low demand periods

📊 Pizza Size-wise Quantity Sales

* Comparison of sizes:

  * S, M, L, XL, XXL
* Large (L) size dominates sales

🏷️ Category-wise Order Distribution

* Categories:

  * Classic
  * Supreme
  * Veggie
  * Chicken

📉 Category-wise Unit Price Analysis

* Shows price variation across categories

🍕 Pizza Order Quantity Distribution

* Donut chart showing contribution of different pizzas

---

🔹 Filters / Slicers

* Pizza Category
* Month
* Pizza Size
* Pizza Name

---

🎯 Key Insights

* 📌 Large (L) pizzas are the most preferred size
* 📌 Classic category has the highest order share (~30%)
* 📌 Sales show slight seasonal variation across months
* 📌 Veggie category has lower pricing compared to others
* 📌 Diverse pizza menu contributes evenly to total sales
